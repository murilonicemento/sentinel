
# Git Workflow Rules

## Purpose
Protect existing work and maintain a reliable change history.

## Repository Safety
- Inspect the working tree before modifying files.
- Preserve unrelated user changes.
- Never discard uncommitted work without explicit authorization.
- Do not rewrite shared history without authorization.
- Do not push changes without authorization.
