
# Dependency Management Rules

## Purpose
Keep dependencies justified, secure, and maintainable.

## General Rules
- Prefer existing project capabilities when sufficient.
- Justify new dependencies before introducing them.
- Avoid duplicate libraries with overlapping responsibilities.
- Verify project compatibility and maintenance status.
- Consider licensing and security implications.
- Do not upgrade major versions without evaluating breaking changes.
